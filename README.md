# CampusFind — Enterprise College Lost & Found Management System

CampusFind is an enterprise-grade full-stack MERN web application engineered for university campuses. It streamlines the lifecycle of reporting lost belongings, cataloging found items into secure custody, verifying claims with matching algorithms, and auditing the physical handover process.

---

## 🎯 Role Workflows & Core Capabilities

### 👨‍🎓 1. Student Portal
- **Report Lost Item:** Submit reports with item title, category, color, brand, location, date/time, and photo attachments.
- **Privacy-Safe Found Item Browsing:** Browse staff-approved items in campus custody without exposure to confidential storage locations or internal notes.
- **AI Match Suggestions:** View candidate item matches generated by the similarity engine.
- **Submit Ownership Claim:** Privately submit identifying evidence, invoice receipts, and distinguishing marks.
- **Claim Status Tracking:** Monitor real-time status progression (`pending` → `under_review` → `additional_information_requested` → `approved` → `completed`).

### 👮‍♂️ 2. Staff / Security Desk Console
- **Custody Intake:** Register found property into campus custody with physical locker coordinates (e.g., "Locker 4B").
- **Inventory Management:** Update item statuses, filter by date/location, and view active custody records.
- **Claim Review Queue:** Inspect student ownership explanations and attached proof documents.
- **Decision Workflow:** Approve claims, request additional proof from student, or reject with feedback.
- **Verified Physical Handover:** Execute in-person handover checklist (identity card inspection & item test), transitioning item to `returned`.
- **Activity & Custody Logs:** View chronological operational log of custody operations.

### 🛡️ 3. Administrative Control Center
- **System-Wide Dashboard:** Live MongoDB statistics on users, lost/found counts, recovery percentage, and pending claims.
- **Visual Analytics:** Dynamic Recharts visualizations covering recovery rates, category distributions, and monthly trends.
- **User & Staff Account Management:** Modify user roles, toggle account statuses (active / inactive), or remove accounts.
- **Immutable Audit Trail:** Review tamper-evident audit logs with actor timestamps, action codes, and event summaries.
- **Category Management:** Create, edit, and organize campus item categories.

## 🛠️ Technology Stack

- **Frontend:** React 19, Vite 8, React Router v7, Tailwind CSS v4, Lucide Icons, Recharts, React Hook Form, Axios.
- **Backend:** Node.js, Express.js (ES Modules), Mongoose, Multer, JSON Web Tokens (JWT), Bcryptjs.
- **Database:** MongoDB (`mongodb://127.0.0.1:27017/campusfind`).
- **Code Quality:** Oxlint, Vite Production Bundler.

## 🚀 Quick Start Guide

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [MongoDB](https://www.mongodb.com/) (running locally on port `27017` or MongoDB Atlas URI)

### 1. Installation
In the project root directory:
```bash
npm install
cd backend && npm install && cd ..
```

### 2. Environment Configuration
Verify or copy the environment configuration:
```bash
# Root environment file (.env)
VITE_API_URL=http://localhost:5000/api
PORT=5000
NODE_ENV=development
CLIENT_URL=http://localhost:3000
MONGODB_URI=mongodb://127.0.0.1:27017/campusfind
JWT_SECRET=campusfind_super_secret_jwt_key_2026
```

### 3. Seed Database (Optional / Initial Setup)
Populate default campus accounts, sample categories, and items:
```bash
npm run seed
```

### 4. Start Development Environment
Run both backend and frontend concurrently with a single command:
```bash
npm run dev
```
- **Frontend Client:** [http://localhost:3000](http://localhost:3000)
- **Backend REST API:** [http://localhost:5000](http://localhost:5000)
